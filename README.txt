TV BOX GAMING - PLAYSTATION EDITION
===================================

Proyecto Android nativo (Kotlin) para Android 12 / Android TV Box.
Interfaz ligera con navegación por control remoto (flechas y OK).

IMPORTANTE:
- Este ZIP contiene el CÓDIGO FUENTE del proyecto, no un APK ya compilado.
- No incluye GTA San Andreas, Minecraft, ROMs, BIOS ni emuladores.
- GTA San Andreas clásico debe estar instalado legalmente en el dispositivo.
- Si tu versión de GTA usa un identificador de paquete diferente, el acceso directo puede necesitar ajuste.
- Los botones Nintendo, Arcade y PlayStation son espacios para abrir emuladores compatibles; todavía no se conectan automáticamente a todos los emuladores.

CÓMO GENERAR EL APK:
1. En una computadora instala Android Studio y Android SDK.
2. Descomprime este ZIP.
3. Abre la carpeta TV_BOX_GAMING en Android Studio.
4. Espera a que Gradle termine de sincronizar (requiere Internet la primera vez).
5. Selecciona Build > Build Bundle(s) / APK(s) > Build APK(s).
6. Android Studio generará el APK dentro de app/build/outputs/apk/debug/.

Requisitos recomendados:
- Android Studio reciente
- JDK 17
- Android SDK Platform 35
- Android 6.0 o superior (minSdk 23); diseñado para Android 12.

Uso:
- Flechas del control: moverse entre tarjetas.
- OK: abrir el juego.
- Atrás: regresar.

Si no tienes computadora, este proyecto también puede abrirse en un entorno de desarrollo Android compatible, pero compilarlo directamente en un TV Box no está garantizado.
